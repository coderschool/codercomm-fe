# Project Setup

Let's start by setting up our React project using Vite, which provides a faster and leaner development experience.

## Create a New Project

Run the following command to create a new project:

```bash
npm create vite@latest codercomm-fe -- --template react
cd codercomm-fe
```

## Install Dependencies

Install the core dependencies:

```bash
npm install react-router-dom @tanstack/react-query @tanstack/react-query-devtools zustand axios react-hook-form @hookform/resolvers yup sonner date-fns jwt-decode react-helmet-async numeral
```

## Set Up Path Aliases

Create a `jsconfig.json` file in your project root:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

## Configure Vite

Update your `vite.config.js`:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

## Create Basic Project Structure

Create the following directory structure:

```
src/
├── components/    # Reusable UI components
├── contexts/      # React contexts
├── features/      # Feature-based modules
├── hooks/         # Custom hooks
├── layouts/       # Page layouts
├── lib/           # Utilities and configuration
├── pages/         # Route pages
├── routes/        # Routing configuration
└── utils/         # Helper functions
```

## Test Your Setup

Update the main.jsx file:

```jsx
import React from 'react';
import { createRoot } from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import { HelmetProvider } from 'react-helmet-async';
import { Toaster } from 'sonner';

import App from './App';

// Import Tailwind CSS
import './index.css';

// Create a React Query client
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      refetchOnWindowFocus: false,
      retry: 1,
      staleTime: 5 * 60 * 1000, // 5 minutes
    },
  },
});

const root = createRoot(document.getElementById('root'));

root.render(
  <React.StrictMode>
    <HelmetProvider>
      <QueryClientProvider client={queryClient}>
        <BrowserRouter>
          <App />
          <Toaster position="top-right" richColors />
        </BrowserRouter>
        {import.meta.env.DEV && <ReactQueryDevtools initialIsOpen={false} />}
      </QueryClientProvider>
    </HelmetProvider>
  </React.StrictMode>
);
```

Create a simple App.jsx file:

```jsx
import React from "react";

function App() {
  return (
    <div className="flex items-center justify-center min-h-screen">
      <div className="text-center">
        <h1 className="text-3xl font-bold mb-4">CoderComm</h1>
        <p className="text-lg">A social network for developers</p>
      </div>
    </div>
  );
}

export default App;
```

Run the development server:

```bash
npm run dev
```

Visit http://localhost:5173/ to see your application. You should see the CoderComm title page.
