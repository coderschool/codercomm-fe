# Introduction to CoderComm

Welcome to CoderComm! In this tutorial, you'll build a social media platform for developers from scratch. This project is designed for beginners who have spent a week or two learning React and are ready for a more complete application.

## What We'll Build

CoderComm is a social network where developers can:
- Create accounts and customize profiles
- Share posts and thoughts
- Comment on posts
- React to posts and comments
- Connect with other developers

## What You'll Learn

By building CoderComm, you'll master:
- Modern React with hooks and functional components
- React Query for efficient API interactions
- Zustand for simple state management
- Authentication and protected routes
- Form handling with React Hook Form
- UI components with Shadcn UI and Tailwind CSS
- Routing with React Router
- Using a REST API

## Prerequisites

- Basic JavaScript knowledge
- React fundamentals (components, props, state)
- Node.js and npm installed on your computer
- A code editor (VS Code recommended)

## Project Structure

We'll build the app in logical steps:
1. Project setup with Vite
2. UI components and layouts
3. Authentication
4. User profiles
5. Posts and comments
6. Friends and connections
7. Testing and deployment

Each step builds on the previous one, and you'll have a working application after each major step.
