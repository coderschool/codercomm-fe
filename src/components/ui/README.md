# UI Components from shadcn/ui

This directory contains UI components from [shadcn/ui](https://ui.shadcn.com/), a collection of reusable components built using Radix UI and Tailwind CSS.

## Components Added

- `button.jsx` - Various button styles with variants
- `card.jsx` - Card containers with header, content, and footer
- `avatar.jsx` - User avatars with image and fallback
- `tabs.jsx` - Tabbed interfaces
- `input.jsx` - Form input fields
- `label.jsx` - Accessible form labels
- `form.jsx` - Form components with validation
- `checkbox.jsx` - Checkboxes
- `select.jsx` - Dropdown select
- `dialog.jsx` - Modal dialogs
- `dropdown-menu.jsx` - Dropdown menus
- `sheet.jsx` - Slide-out panels

## Usage

These components are imported from the `/components/ui` directory:

```jsx
import { Button } from "@/components/ui/button";
import { Card, CardHeader, CardContent, CardFooter } from "@/components/ui/card";
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar";
```
